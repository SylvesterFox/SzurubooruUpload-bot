# Telegram-загрузчик для Szurubooru

Бот принимает файлы в личном чате и создаёт пост через REST API локального Szurubooru. Поддерживаются `.jpg`, `.png`, `.webm`, `.mp4`, `.swf`, `.avif`, `.heif`, `.heic`. Слова из подписи становятся тегами; у хештегов `#` автоматически убирается. Уровень безопасности задаётся настройкой `DEFAULT_SAFETY`.

Для JPG, PNG, AVIF, HEIF и HEIC до 10 МБ бот может найти совпадение через [FuzzySearch](https://fuzzysearch.net/) и добавить теги с e621 через его API. Настройте `FUZZYSEARCH_API_KEY` и укажите свой контакт в `E621_USER_AGENT`. Поиск необязательный: если он недоступен или совпадения нет, загрузка продолжается с тегами из подписи.

Можно отправить сообщением ссылку на публикацию с `bsky.app`, `x.com`/`twitter.com` или `e621.net`. Для e621 бот получает файл и теги напрямую через API, объединяет теги с подписью и сохраняет URL поста как источник. Для Bluesky и X бот скачивает до `MAX_LINK_FILES` файлов через `gallery-dl`. Если отправить файл со ссылкой в подписи, загрузится отправленный файл, а ссылка останется источником.

## Запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Узнайте свой Telegram ID (например, через бота `@userinfobot`).
3. Скопируйте `.env.example` в `.env` и заполните токен, разрешённые Telegram ID, URL Szurubooru и учётные данные API.
4. В папке проекта выполните:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   py -m pip install -r requirements.txt
   py bot.py
   ```

   Для Linux/macOS активируйте окружение командой `source .venv/bin/activate`, затем запустите `python bot.py`.

Бот должен иметь сетевой доступ к `SZURU_URL`. Если он запущен в Docker, `127.0.0.1` указывает на контейнер бота, а не на контейнер Szurubooru. Если Szurubooru запущен непосредственно на этом же компьютере, укажите в `.env` `SZURU_URL=http://host.docker.internal:8080`. Если оба сервиса в Docker, подключите бота к общей сети и используйте имя сервиса Szurubooru, например `http://szurubooru:8080`.

## Запуск в Docker

1. Подготовьте `.env` по инструкции выше. Проверьте, что `SZURU_URL` доступен из контейнера (см. варианты выше).
2. В папке проекта запустите:

   ```powershell
   docker compose up -d --build
   ```

3. Просмотр логов и остановка:

   ```powershell
   docker compose logs -f
   docker compose down
   ```

Если для сайта нужны cookies `gallery-dl`, смонтируйте файл в сервис `telegram-uploader` как read-only volume в `compose.yaml` и укажите соответствующий путь в `GALLERY_DL_COOKIES_FILE`. Не добавляйте файл cookies в Git.

## Форматы и ограничения

Загрузчик отправляет исходный файл без перекодирования в endpoint `POST /api/posts/`. Сам сервер должен поддерживать соответствующий формат и иметь доступные обработчики для него. Стандартный Szurubooru заявляет поддержку JPG, PNG, MP4, WEBM и SWF; поддержка AVIF/HEIF/HEIC зависит от используемой сборки и её библиотек обработки изображений. Если API отклоняет такой формат, потребуется добавить поддержку на сервере.

Также действуют ограничения Telegram на скачивание файлов ботом (обычный Bot API допускает скачивание до 20 МБ) и заданный `MAX_FILE_MB`. Чтобы принимать большие файлы, потребуется локальный Telegram Bot API Server.

Для Bluesky и X загрузчик использует `gallery-dl`. Для сайтов с авторизацией можно экспортировать cookies в Netscape формате и задать путь в `GALLERY_DL_COOKIES_FILE`. Если путь относительный (например, `./cookies.txt`), он считается от папки проекта. Файл передаётся загрузчику как параметр cookies:

Для сайтов, которые поддерживает gallery-dl, можно вместо файла задать `GALLERY_DL_COOKIES_FROM_BROWSER=firefox` либо `chrome`, чтобы прочитать cookies из профиля браузера на машине бота.

Задайте только один из этих параметров. Cookies не гарантируют прохождение Cloudflare challenge. Не отправляйте и не публикуйте файл cookies: он даёт доступ к вашей сессии. Поддержка страниц зависит от изменений на сайтах; бот берёт URL источника из сообщения.

Доступ закрыт по умолчанию: `TELEGRAM_ALLOWED_USERS` обязателен. Перечислите ID через запятую. Данные `.env` не публикуйте.
